### 5.2 Component Specifications

#### Header
- **Position**: Fixed, top 0, z-index 50
- **Background**: `#0a0a0a` with 80% opacity blur
- **Height**: 60px
- **Content**: Logo left (monospace "OuiRise"), Nav center (OUR STYLE, DEPLOYMENTS, OFFER, LEADERSHIP), CTA right ("ACCESS")
- **Border**: 1px bottom border `#1a1a1a`

#### Hero
- **Height**: 100vh or min-height 600px
- **Background**: True black with subtle noise texture (CSS noise or SVG)
- **Typography**: 
  - "ACCESS GRANTED" - 48px-72px, monospace, tracking wide
  - Subtext - 18px, sans-serif, muted gray
- **Animation**: Cursor blink after "ACCESS GRANTED", typewriter effect optional
- **CTA**: Border button, transparent bg, white border, hover fills white text turns black

#### Recent Deployments
- **Layout**: CSS Grid, 3 columns desktop, 1 column mobile
- **Card Style**: 
  - Background: `#141414`
  - Border: 1px `#1f1f1f`
  - Hover: Border brightens to `#333`, slight lift transform
  - Image: 16:9 aspect ratio, grayscale or duotone filter
  - Tags: Monospace small caps, muted color
- **Content**: Project name, tech stack tags, "// Built by OuiRise" footer

#### What We Offer (Pricing)
- **Card Style**:
  - Background: `#141414`
  - MVP card: Accent border (orange or gold), "POPULAR" badge
  - PROTO/ENTERPRISE: Standard border `#1f1f1f`
- **Typography**:
  - Tier name: Monospace, all caps
  - Price: Hidden (consultation model) or "Custom"
  - Features: Checkmark or bullet list, clean sans
- **Buttons**: Solid fill for MVP, outline for others

#### Leadership Layer
- **Layout**: Split 50/50 or 40/60 (image/text)
- **Image**: Professional but not corporate, perhaps B&W or warm tone
- **Quote**: Italic or serif font for contrast
- **Credentials**: Small monospace list (UNC, Change Management, etc.)
