## Operational Playbook

### Mission Start

**Trigger**: User requests math-heavy task

**Example**: *"Solve 4x - 2y = 6 for y-intercept"*

**Signal Chain**: Heavy (DeepSeek-R1:8B) → Vision (Kimi) → Output (E-ink)

### Execution Flow

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  INPUT (Paper)  │────▶│  VISION SLICE   │────▶│  REASONING      │
│  Bluetooth Cam  │     │  Kimi K2.5 OCR  │     │  Heavy Slot     │
└─────────────────┘     └─────────────────┘     └─────────────────┘
                                                        │
                        ┌─────────────────┐            │
                        │  OUTPUT SLICE   │◀───────────┘
                        │  E-ink Display  │     y = 2x - 3
                        └─────────────────┘     y-intercept = -3
```

**Step-by-Step**:
1. Kimi K2.5 → OCR → text normalization
2. Tiny Model → basic cleanup → tokenization
3. Heavy → chain-of-thought → solution derivation
4. Output → E-ink strip → formatted result

### Audit Protocol

- Mission log updated → fleet-wide timestamp
- Shadow slot validates output for typos → "cleaner tool" integration
- All reasoning steps logged for verification
