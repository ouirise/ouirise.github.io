Executive Summary

TroH (Tactical Hacking) is a decentralized execution framework leveraging fleet components for open, federated, no-extraction operations. This skill build demonstrates the 0KK philosophy in action: mutual assured survival through accessible tooling.

Core Use Case: Pen-based assistive technology for educational equity — reducing cheating tool costs from $150 → $0 via open-source fleet deployment.

Fleet Integration Breakdown

1. Vision Slice (Kimi K2.5)

Attribute Specification
Role Multimodal input processing (camera → text → structured data)
Slot SHADOW (speed) + HEAVY (reasoning) — Hybrid function
Deployment Modes

Pen Mode: - Bluetooth camera reads paper - Kimi K2.5 OCR → text cleanup - Output: Bone-conduction audio (stealth exfiltration)

Offline Mode: - Ollama local slice (qwen2.5 7B) - Handles OCR → vision → reasoning without internet - Fallback when cloud unavailable

2. Reasoning Slice (Tiny Model + Kimi)

Attribute Specification
Role Text cleanup → math logic → chain-of-thought reasoning
Slot HEAVY (DeepSeek-R1:8B) — vertical slice for complex reasoning

Execution Pipeline: 1. Tiny model (7B) → first pass cleanup 2. Kimi K2.5 → advanced math/symbolic reasoning 3. Output → E-ink/OLED strip → "solution layer"

3. Output Slice (Output Device)

Attribute Specification
Role Deliver solution in user-defined format
Slot SHADOW (speed) — minimal footprint
Formats OLED display, bone-conduction audio, stealth vibration
