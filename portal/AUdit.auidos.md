## ⚡ Commands

### 🔍 `audit.compliance`
```bash
audit.compliance --org {{name}} --type 501c3
```
**Output:** PSSH packet with gap analysis, 990 status, action plan.

### 🏗️ `audit.infrastructure`
```bash
audit.infrastructure --stack {{current}} --risk lock-in
```
**Output:** Vendor risk matrix, OSS alternatives, migration roadmap.

### 📅 `audit.content`
```bash
audit.content --days 90 --tone authority
```
**Output:** 90-day calendar, topics, code samples, case studies.

### 🤖 `audit.workflow`
```bash
audit.workflow --domain {{process}} --auto true
```
**Output:** Agent workflow map, inputs, gates, outputs, error handling.

### 📧 `audit.onboard`
```bash
audit.onboard --touches 5 --tone value-first
```
**Output:** Email sequence, CTAs, compliance audit call funnel.
